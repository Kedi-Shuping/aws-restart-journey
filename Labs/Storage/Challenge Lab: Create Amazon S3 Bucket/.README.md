# Challenge Lab: Create Amazon S3 Bucket

## Overview

This project demonstrates how to create an Amazon S3 bucket, upload an object, and make it publicly accessible using the AWS CLI and AWS Management Console.

During this lab, I created a bucket (`kshubucket004`), uploaded a text file (`hello.txt`), configured public access by disabling Block Public Access and enabling ACLs, and successfully accessed the object through a browser.

- Amazon S3
- AWS CLI

## Project Workflow

1. Created an S3 bucket with a unique name
2. Created a text file (`hello.txt`) with sample content
3. Uploaded the file to the S3 bucket
4. Disabled Block Public Access on the bucket
5. Enabled ACLs via Object Ownership settings
6. Made the object publicly accessible using `put-object-acl`
7. Verified access via the public URL
8. Listed bucket contents using the AWS CLI

---
## Challenges Encountered


The put-object-acl command initially failed because BlockPublicAccess was enabled. I resolved this by disabling Block Public Access and changing Object Ownership to BucketOwnerPreferred in the S3 console, which allowed ACLs to work.
