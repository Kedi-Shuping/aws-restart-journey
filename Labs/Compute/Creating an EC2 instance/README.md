# Creating an Amazon EC2 Instance

## Objective

Launch an Amazon EC2 instance using the AWS Management Console.

## AWS Services Used

- Amazon EC2
- Amazon VPC
- Amazon Machine Image (AMI)
- Security Groups
- Key Pairs

## Lab Summary

In this lab, I launched an Amazon EC2 instance, selected an Amazon Machine Image (AMI), chose an instance type, configured networking and security settings, and connected to the instance.

## Skills Demonstrated

- Launching an EC2 instance
- Selecting an AMI
- Choosing an instance type
- Configuring security groups
- Creating and using key pairs
- Understanding the EC2 launch workflow

## Outcome

Successfully launched and connected to an Amazon EC2 instance while I gained practical experience with AWS compute services.
