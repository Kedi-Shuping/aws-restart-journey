# Database Labs

This folder contains my database labs completed during the AWS re/Start programme.

## Labs

- [Build and Access an RDS Server](Build%20and%20Access%20an%20RDS%20Server/README.md) — setting up an Amazon RDS for MySQL database, connecting from EC2, working with SQL tables, and troubleshooting connection and query problems.
- [Introduction to Amazon Aurora](Introduction%20to%20Amazon%20Aurora/README.md) — creating an Aurora MySQL-compatible cluster, connecting from an EC2 Command Host, and querying the `world` database.
- [Migrating to Amazon RDS](Migrating%20to%20Amazon%20RDS/README.md) — migrating a local MariaDB database to Amazon RDS for MariaDB.
- [Introduction to Amazon DynamoDB](Introduction%20to%20Amazon%20DynamoDB/README.md) — creating a music library table, adding and updating items, and retrieving records using Query and Scan operations.

## Topics covered

- Amazon RDS
- Amazon Aurora
- Amazon DynamoDB
- Database Fundamentals
- Relational Databases
- NoSQL Databases
- Database Security
- Database Backup and Recovery
