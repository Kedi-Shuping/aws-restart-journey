# Networking Labs

This folder contains my networking-related AWS re/Start labs.

## Labs

- [Troubleshooting a VPC](Troubleshooting-a-VPC/README.md) — diagnosed routing and Network ACL issues using VPC Flow Logs.
- [Route 53 Failover Routing](Route%2053%20Failover%20Routing/README.md) — demonstrated DNS failover between two Availability Zones using Route 53 health checks.

Topics include:
- Amazon VPC
- Route 53
- Security Groups and Network ACLs
- DNS and availability

Each lab folder includes an overview, AWS services used, practical evidence, skills demonstrated, and key lessons learned.
