# Project Brief

## Praesignis AWS re/Start Special Projects

**Project 3 — Create your interactive chatbot using AWS Lex**

## Project Overview

The project requires learners to create an interactive chatbot using Amazon Lex. The work is divided into two parts:

1. Create a basic chatbot with one intent, related utterances, and a response.
2. Extend the chatbot into a knowledge-check quiz with branching logic and prepare a presentation and live demonstration.

## Part 1 — Basic Chatbot

The first part requires learners to:

- Create a bot in Amazon Lex.
- Configure the language as English (ZA).
- Create one intent.
- Add a topic-specific utterance.
- Configure a response.
- Save, build, and test the bot.

## Part 2 — Knowledge Quiz

The client scenario describes an educational startup that wants a chatbot to quiz learners on an AWS topic.

The quiz must:

- Provide an utterance to start the quiz.
- Present a multiple-choice question.
- Handle correct and incorrect answers with appropriate feedback.
- Allow the learner to continue to another question.
- Use branching logic to support the quiz flow.

The supplied example uses Amazon S3, with questions about what S3 stands for and what it is mainly used for. The brief allows learners to choose another AWS service or topic.

## Presentation Requirements

The presentation should cover:

1. **Introduction to Amazon Lex** — explain what Amazon Lex is, its core capabilities, and how it supports conversational interfaces.
2. **Client Requirements** — explain the fictional client's requirements for an educational quiz chatbot.
3. **Solution Overview** — describe the quiz structure, user interactions, feedback, and conversation flow.
4. **Technical Approach** — explain how intents, utterances, and branching were used, including challenges and how they were addressed.

## Live Demonstration

The demonstration should:

- Open Amazon Lex and show the chatbot.
- Start the quiz using a quiz-related utterance.
- Demonstrate a correct answer.
- Demonstrate an incorrect answer.
- Show how the learner continues or retries.
- Highlight the quiz interaction flow.

## Learning Outcomes

The project is intended to develop skills in chatbot development, problem-solving, technical understanding of AWS services, and communication/presentation.
