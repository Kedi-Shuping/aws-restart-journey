# AWS Lex Quiz Bot

## Project Overview

This project was completed as part of the Praesignis AWS re/Start Special Projects. It focuses on creating an interactive knowledge-check chatbot using Amazon Lex.

The chatbot is designed around an educational use case. Learners can start a quiz, answer multiple-choice questions, receive feedback, and continue through the quiz.

## Project Objectives

- Create and configure a chatbot using Amazon Lex.
- Use intents and sample utterances to recognise user requests.
- Build a knowledge quiz around a selected AWS topic.
- Use branching logic to handle correct and incorrect answers.
- Test the conversation flow and demonstrate the chatbot to an audience.

## AWS Services & Tools

- **Amazon Lex V2** — chatbot creation, intent configuration, utterances, responses, and conversation flow.

Additional services will be documented if they form part of the final implementation.

## Chatbot Functionality

The project brief requires the quiz experience to:

- Recognise requests such as starting the quiz.
- Present multiple-choice questions.
- Provide clear feedback for correct and incorrect answers.
- Allow the learner to continue to the next question or retry.
- Maintain a clear and engaging interaction flow.

The final questions, intents, branching configuration, and tested conversation examples will be documented here as the implementation is reviewed.
