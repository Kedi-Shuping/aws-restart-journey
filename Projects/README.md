
# Project 1 – Restaurant Static Website on AWS

## Project Overview

This repository contains my Amazon re/Start Project 1, where I will design and deploy a static restaurant website using Amazon Web Services (AWS).

The project demonstrates how a traditional restaurant can migrate its digital presence to the cloud to improve customer bookings, order management, and operational efficiency.

This project will also include a presentation explaining the business benefits of migrating the restaurant's infrastructure to AWS.

---

## Project Objectives

- Build a responsive static restaurant website
- Host the website using Amazon S3
- Implement user authentication with Amazon Cognito
- Store customer and booking information in a cloud database
- Demonstrate how AWS services solve real business challenges
- Present the migration benefits through a business presentation

---

## Planned AWS Services

- Amazon S3
- Amazon Cognito
- Amazon DynamoDB or Amazon RDS
- AWS IAM
- AWS CloudFront (optional)
- Amazon Route 53 (optional)
